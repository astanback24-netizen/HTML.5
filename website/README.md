# Loaded & Locked In Training Academy Website

A professional firearms training academy website built with HTML, CSS, and JavaScript.

## Project Structure

```
website/
├── index.html          # Main HTML file
├── css/
│   └── style.css      # Custom styles
├── js/
│   └── script.js      # JavaScript functionality
├── images/            # Image folder (for future use)
└── README.md          # This file
```

## Features

✅ **Responsive Design** - Works on all devices (mobile, tablet, desktop)
✅ **Modern UI** - Clean, professional design with Tailwind CSS
✅ **Dark Theme** - Eye-friendly dark color scheme
✅ **Smooth Animations** - Fade and scroll animations
✅ **Mobile Navigation** - Hamburger menu for small screens
✅ **Interactive Elements** - Expandable FAQ section
✅ **Accessibility** - WCAG compliant with proper semantic HTML
✅ **Social Media Links** - Facebook, Instagram, YouTube integration

## Sections

1. **Navigation Header** - Sticky header with mobile support
2. **Hero Section** - Eye-catching welcome banner
3. **About Us** - Company mission and values
4. **Courses** - 4 main course offerings
5. **Testimonials** - Client success stories
6. **Call to Action** - Enrollment section
7. **Contact** - Contact information and social links
8. **FAQ** - Frequently asked questions
9. **Footer** - Copyright and additional info

## Technologies Used

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework
- **Vanilla JavaScript** - No dependencies
- **Google Fonts** - Inter font family

## Getting Started

1. Open `index.html` in a web browser
2. No build process or dependencies required
3. Customize content in `index.html` as needed
4. Modify styles in `css/style.css`
5. Add custom functionality in `js/script.js`

## Customization

### Colors
Main color: Red (#dc2626)
Background: Gray-900 (#111827)
Cards: Gray-800 (#1f2937)

### Content
Edit the text and links directly in `index.html`

### Images
Add images to the `images/` folder and reference them in HTML
